# SuLMod - Mod Geode

Mod latihan buat Geometry Dash dengan 2 fitur:

1. **Tampilkan Hitbox** — kotak hitbox player muncul real-time saat main, warna bisa diubah lewat setting.
2. **Speedhack** — atur kecepatan gameplay pakai kelipatan (0.1x - 3.0x), cocok buat latihan bagian susah dengan slow motion.

## Catatan

- Setting hitbox & speed bisa diubah dari menu Mods > SuLMod di dalam game (tidak perlu build ulang).
- Speedhack di sini murni untuk latihan offline.
